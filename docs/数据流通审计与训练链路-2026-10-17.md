## 二、发现的问题

1. **训练侧是死路**：预处理已产出 `data/splits/{train,val,test}.{csv,npz}`、`vocab.json`、
   `preprocessor.json`，但 `src/models`、`src/training` 的 `build/forward/train_model` 全抛
   `NotImplementedError`，仓库里没有任何代码消费这些产物。
2. **评估/可视化无法产出**：`src/evaluation`、`src/visualization` 同为骨架，报告第 5、6 章没有数据来源。
3. **一键脚本 `scripts/train.sh` 只打印 TODO**，README 中「训练命令」不可执行。
4. 小问题：`tests/test_skeleton.py` 把「模型 forward 必须抛 NotImplementedError」写成了断言，
   实现模型后需同步改为行为测试；CI 的导入检查未覆盖新模块。

未在本次处理（已在 README / Issue 中登记）：

## 三、本次实现内容

| 模块 | 文件 | 内容 |
| --- | --- | --- |
| 模型 | `src/models/base.py` | 检查点保存/加载（附 `config.json` / `metadata.json`）、`TorchModelMixin` |

## 五、依赖与兼容性

- 训练与模型测试需要 PyTorch（未放进默认 `requirements.txt`，见其中注释）；无 torch 时
  `pytest` 自动跳过模型/训练用例，服务、预处理、数据项目等测试照常运行。
- gensim / scikit-learn / matplotlib / seaborn / wordcloud 缺失时，相应函数给出带安装命令的
  `ImportError`，模块本身仍可导入（所有重依赖都在函数内延迟导入）。
- 标签顺序、词表 id 约定（`<pad>=0` / `<unk>=1`）、`data/processed` 资源契约均沿用既有
  预处理产物，没有改动前后端接口，也没有改动模型/推理的服务契约。
