# 课程设计报告大纲

> 要求：不少于 **5000 字**，建议使用毕业论文模板。各章下方列出必须覆盖的内容与对应得分点。

## 封面

课程名称、题目「网站用户评论情感分析系统」、小组成员与学号、指导教师、日期。

## 摘要（可选）

研究问题、方法（词向量 + 深度模型）、主要结果（两个模型的关键指标对比）、结论。

## 1 项目背景与目标

- 网络评论数据规模与情感分析的应用价值（舆情监控、电商、产品改进）；
- 本项目的具体目标：端到端完成「数据 → 模型 → 演示」；
- 任务定义：输入一条评论文本，输出情感极性（正面 / 负面）与置信度。

## 2 数据说明

- 数据来源（公开数据集名称与链接，或爬虫站点），**采集时间**；
- 数据规模：总条数、训练 ≥ 8000、测试 ≥ 2000、正负样本比例；
- 标注方式：已有标注，或自采数据集的标注规范 + 抽样一致性（Kappa）；
- 划分方式：训练 : 验证 : 测试 ≈ 7 : 1 : 2 的具体做法与随机种子。

## 3 数据清洗与探索性分析

- 清洗规则：去 URL、HTML 标签、特殊符号、重复样本、空样本；
- 探索性分析：文本长度分布、标签分布图、高频词统计；
- 异常与噪声处理说明。

## 4 文本预处理与特征表示

- 中文 jieba 分词 / 英文分词 + 小写化，停用词表来源；
- 截断补齐 `max_len = 200` 的依据；
- 词表构建 `min_freq ≥ 3`，**给出词表规模、平均文本长度、标签分布统计**；
- 词向量：Word2Vec / GloVe 的参数设置与训练细节，OOV 处理。

## 5 模型构建与实验设置

- 所选两种深度模型的**原理阐述**（结构图、公式），说明为何适合中文短文本；
- TextCNN：卷积核尺寸、通道数、池化方式；
- BiLSTM-Attention：隐藏层维度、层数、注意力计算方式；
- 实验设置：损失函数、优化器、学习率、batch size、epochs、早停策略、设备（CPU/GPU）；
- 实验环境：Python / PyTorch / 依赖版本。

## 6 模型评价与结果分析

- 评价指标定义：Accuracy、Precision、Recall、F1、混淆矩阵；
- **对比表**：两个模型在测试集上的全部指标；
- 训练过程曲线：损失 / 准确率（训练集 vs 验证集），分析过拟合或欠拟合；
- 混淆矩阵热力图分析；
- 正负评论词云对比；
- **错误分析**：列举典型错误样例，分析原因（反讽、转折、否定词、领域词）；
- 可选加分：Attention 权重可视化，说明哪些词对情感判定贡献最大。

## 7 问题讨论与改进建议

- 遇到的问题与解决过程；
- 模型局限：领域迁移、反讽识别、中性样本、类别不平衡；
- 改进方向：预训练语言模型、数据增强、超参调优、集成学习。

## 8 小组成员分工

表格：姓名、学号、承担工作（数据、模型、前端、报告）、工作量占比。

## 参考文献

数据集引用、Word2Vec / GloVe / TextCNN / BiLSTM / Attention / BERT 原始论文、工具文档，格式统一。
