# 开发路线图

本文件把课程要求拆成可执行的实现顺序。骨架已就绪的模块，按下面顺序逐个填充即可。

## 阶段一：数据（对应要求 1、2）

1. **采集 已实现（2026-10-17 两轮改进）** `src/crawler/`
   - 选择公开数据集（ChnSentiCorp / 外卖评论 / 酒店 / 购物）或自行爬取；
   - 爬虫检查 robots.txt、限速（2.5 秒 + 抖动，风控自适应降速），并把「站点 / URL / 采集时间 / 条数」写入 `data/raw/来源说明.md`；
   - B 站接口版：WBI 签名 / 风控退避 / 文本标准化 / 断点续爬 / `sub_done` 楼中楼断点 / `--max-seconds` 时间预算，入口 `python -m src.crawler bilibili --bvid ...`；
   - 公开数据集：`src/crawler/datasets.py`（下载 + 校验 + 来源登记 + `import_labeled_csv`）；标注：`src/crawler/labeling.py`（分层抽样 + 合并校验）；
   - 通用 HTML 版：`python -m src.crawler html --url ... --source ...`；
   - 实测效率与审查记录见 README 第十二节、`docs/第二轮全面改进-2026-10-17.md` 与 `docs/爬虫代码审查与改进-2026-10-17.md`。
2. **清洗 + 分词 已实现** `src/preprocessing/`
   - 中文 jieba 分词，英文分词 + 小写化；
   - 去停用词、URL、HTML 标签、特殊符号；
   - `max_len = 200` 截断补齐（默认值见 `.env.example`）。
3. **词表与统计 已实现** `src/preprocessing/`
   - 词表 `min_freq ≥ 3`；
   - 输出 `outputs/stats/dataset_stats.json`：词表规模、平均文本长度、标签分布。
4. **划分 已实现** `data/splits/`
   - 训练 : 验证 : 测试 ≈ 7 : 1 : 2，固定随机种子 `SEED=42`，有 video_id 时按视频分组。
   - 入口：`python -m src.preprocessing --input data/raw/comments_labeled.csv`；样例调试加 `--allow-small-dataset`。
   - 先划分再只用训练集建词表；产出 CSV、NPZ、标签映射和预处理资源快照供下游训练与推理共用。
   - ✅ 真实语料已验证：`waimai_10k` + `ChnSentiCorp` 合并均衡 18,644 条，split 13,029 / 1,861 / 3,723，
     `course_requirements_met=true`（数据不入库，命令见 README 第四节）。

## 阶段二：特征表示（对应要求 2）✅ 已实现（2026-10-17）

`src/embeddings/`：训练 Word2Vec（或加载 GloVe），输出到 `models/word2vec/`，
记录维度、窗口大小、最小词频等参数。

## 阶段三：模型与训练（对应要求 3、6）✅ 已实现（2026-10-17）

`src/models/` 提供两个模型骨架，二选一为主、另一个作对比：

| 模型 | 文件 | 特点 |
| --- | --- | --- |
| TextCNN | `cnn.py` | 多尺寸卷积核提取 n-gram 特征，训练快，基线 |
| BiLSTM-Attention | `bilstm_attention.py` | 双向上下文 + 注意力权重，可做 Attention 可视化（加分项） |
| BERT 微调（可选） | `src/models/` 预留 | 效果最好，成本最高 |

在 `src/training/` 实现统一训练循环（早停、保存 best 检查点、写训练日志到 `outputs/logs/`）。

## 阶段四：评估与可视化（对应要求 4、6）✅ 已实现（2026-10-17）

- `src/evaluation/`：Accuracy / Precision / Recall / F1 / 混淆矩阵，输出对比表（加分项：错误分析）。
- `src/visualization/`：
  1. 损失 / 准确率曲线（训练 vs 验证）→ `outputs/figures/loss_curve.png`、`accuracy_curve.png`
  2. 混淆矩阵热力图 → `outputs/figures/confusion_matrix_*.png`
  3. 正负评论词云各一张 → `outputs/figures/wordcloud_positive.png`、`wordcloud_negative.png`
  4. （可选，加分）Attention 权重可视化 → `outputs/figures/attention_heatmap.png`

## 阶段五：系统演示（对应要求 3）✅ 已实现（情感部分为占位）

1. **推理服务** `src/inference/`（FastAPI，:8000）
   - 模型加载与预测逻辑抽成独立函数，便于替换；
   - 接口契约见 `docs/API契约.md`。
2. **B 站视频任务** `src/videos/`（:8000）
   - 输入 BV 号 → 任务状态机（排队/爬取/处理/完成/失败）→ 详情接口；
   - 爬取与情感推理目前走 `src/videos/placeholder.py` 的占位实现，接入点已在其中标注。
3. **数据项目与单独评论** `src/artifacts/`（:8000）
   - 界面上传爬虫 CSV → 落盘 `data/uploads/<项目id>/` → 复用 clean 管线产出
     `initial.csv` / `clean.csv` / `excluded.csv` 三张表；
   - 逐条情感复用 `src/inference/service.py:predict_rule_based`（`method=rule_placeholder`）；
   - 单独评论集中存 `data/uploads/solo_comments.json`；
   - `POST /api/artifacts/{id}/open` 可在服务器本机用系统程序打开 CSV，
     `GET .../path` 只读返回路径（不打开程序）。
4. **前端** `frontend/`（Vue 3 + Vite，:3000）
   - 左栏三段：**数据项目**（上传的爬虫数据）/ **单独评论** / **视频任务**，各自可收起；
   - 数据项目详情：三张表切换 + 分页 + 可展开逐条评论 + 聚合图表词云，操作按钮置底；
   - 单独评论详情只渲染原文/极性/置信度，不渲染图表；
   - 另有单条预测 / 批量预测 / 实验可视化 / 模型对比四个页面；
   - 通过 Vite 代理访问 :8000；后端未启动时可开 `frontend/mock/` 演示（`VITE_USE_MOCK=0` 关闭）。
