# 开发路线图

本文件把课程要求拆成可执行的实现顺序。骨架已就绪的模块，按下面顺序逐个填充即可。

## 阶段一：数据（对应要求 1、2）

1. **采集** `src/crawler/`
   - 选择公开数据集（ChnSentiCorp / 外卖评论）或自行爬取；
   - 爬虫必须检查 robots.txt、限速，并把「站点 / URL / 采集时间 / 条数」写入 `data/raw/来源说明.md`。
2. **清洗 + 分词** `src/preprocessing/`
   - 中文 jieba 分词，英文分词 + 小写化；
   - 去停用词、URL、HTML 标签、特殊符号；
   - `max_len = 200` 截断补齐（默认值见 `.env.example`）。
3. **词表与统计** `src/preprocessing/`
   - 词表 `min_freq ≥ 3`；
   - 输出 `outputs/stats/dataset_stats.json`：词表规模、平均文本长度、标签分布。
4. **划分** `data/splits/`
   - 训练 : 验证 : 测试 ≈ 7 : 1 : 2，固定随机种子 `SEED=42`，划分方式写入报告。

## 阶段二：特征表示（对应要求 2）

`src/embeddings/`：训练 Word2Vec（或加载 GloVe），输出到 `models/word2vec/`，
记录维度、窗口大小、最小词频等参数。

## 阶段三：模型与训练（对应要求 3、6）

`src/models/` 提供两个模型骨架，二选一为主、另一个作对比：

| 模型 | 文件 | 特点 |
| --- | --- | --- |
| TextCNN | `cnn.py` | 多尺寸卷积核提取 n-gram 特征，训练快，基线 |
| BiLSTM-Attention | `bilstm_attention.py` | 双向上下文 + 注意力权重，可做 Attention 可视化（加分项） |
| BERT 微调（可选） | `src/models/` 预留 | 效果最好，成本最高 |

在 `src/training/` 实现统一训练循环（早停、保存 best 检查点、写训练日志到 `outputs/logs/`）。

## 阶段四：评估与可视化（对应要求 4、6）

- `src/evaluation/`：Accuracy / Precision / Recall / F1 / 混淆矩阵，输出对比表（加分项：错误分析）。
- `src/visualization/`：
  1. 损失 / 准确率曲线（训练 vs 验证）→ `outputs/figures/loss_curve.png`、`accuracy_curve.png`
  2. 混淆矩阵热力图 → `outputs/figures/confusion_matrix_*.png`
  3. 正负评论词云各一张 → `outputs/figures/wordcloud_positive.png`、`wordcloud_negative.png`
  4. （可选，加分）Attention 权重可视化 → `outputs/figures/attention_heatmap.png`

## 阶段五：系统演示（对应要求 3）

1. **推理服务** `src/inference/`（FastAPI，:8000）
   - 模型加载与预测逻辑抽成独立函数，便于替换；
   - 实现接口契约（见根 README 第五节）。
2. **前端** `frontend/`（Vue 3 + Vite，:3000）
   - 单条预测 / 批量上传 / 可视化 / 模型对比四个页面；
   - 通过 Vite 代理访问 :8000。

## 阶段六：报告与交付

- 按 `docs/课程设计报告大纲.md` 撰写 ≥ 5000 字报告；
- 用 `docs/验收检查清单.md` 自查评分点。

## 一键脚本

`scripts/` 下脚本为占位，实现后应可直接运行：

| 脚本 | 作用 |
| --- | --- |
| `get_data.sh` | 下载公开数据集或运行爬虫 |
| `split_data.sh` | 按 7:1:2 划分数据集 |
| `train.sh` | 预处理 + 训练 + 评估 + 出图 |
| `serve.sh` | 启动 FastAPI 推理服务 |
