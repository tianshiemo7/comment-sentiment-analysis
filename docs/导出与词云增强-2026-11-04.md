## 一、功能与接口

| 功能 | 接口 / 实现 |
| --- | --- |
| 数据项目导出 | `GET /api/artifacts/{id}/download?stage=initial\|clean\|excluded`（原样 CSV，UTF-8 BOM） |
| 视频任务导出 | `GET /api/videos/{bvid}/download?stage=crawl\|clean`（`crawl.json` / `clean.json` 实时转 CSV，clean 追加 `raw_text`） |
| 词云词量 60 | `src/videos/placeholder.py: KEYWORDS_PER_SIDE=60`、`src/artifacts/pipeline.py: KEYWORD_LIMIT=60` |
| 旧视频任务回填 | `VideoService._effective_keywords`：旧 detail 词量不足时用已落盘 `clean.json + analyze.json` 只读重算，不重新推理、不改历史文件 |
| Python 词云图 | `GET /api/videos/{bvid}/wordcloud-image`、`GET /api/artifacts/{id}/wordcloud-image?tone=positive\|negative`（wordcloud 库渲染、任务目录缓存、mtime 失效、`download=true` 下载） |
| 前端 | 数据项目底部三导出按钮；视频完成/等待态导出按钮；词云卡片「前端渲染 / Python 图」切换（懒加载、失败中文提示并回退）、字号随词量自适应 |

## 五、已知说明

- 导出 CSV 使用标准 CSV 转义：评论正文里的逗号、引号、换行会出现在带引号的字段中，
  用 Excel / `csv` 模块读取行数准确（不要用 `splitlines()` 数行）。
- Python 词云图依赖 `wordcloud`（requirements.txt 已含）；缺失时接口返回 503、
  前端自动回退 ECharts；中文字体可用 `WORDCLOUD_FONT` 指定。
- 旧任务回填在 detail 请求时计算（约 0.4~2s，随评论量增长），只读、不落盘；
  新分析的任务直接产出 60 词，无此开销。
