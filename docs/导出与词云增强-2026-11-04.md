## 三、独立 QA 发现与修复（并发渲染竞态）

独立验收队友用 30 个非法参数、全量逐字段比对与并发探测复核后，确认功能正确，同时发现：

- **M1（Medium）**：`render_frequencies_to_png` 原先使用固定临时名 `<stem>.tmp.png`。
  Windows 上并发请求同一 tone 的冷缓存时，多个线程写同一个 tmp，`os.replace` 遇到文件锁
  → 实测 10 并发 × 6 轮有 **46/60 个 HTTP 500**（直接调函数 35/40 抛 `PermissionError(WinError 32)`）。
- **根因有两层**：固定临时名只是其一；改用唯一临时文件后，隔离实验仍复现出
  **44/200 次 WinError 5（Access denied）** —— 多线程**同时 `os.replace` 到同一目标**的
  Windows rename 竞争，两处都要处理。
- **修复**（commit `aa6875f` + `020fa8f`）：
  1. `tempfile.mkstemp` 生成**唯一临时文件**（父目录内、`.png` 后缀，关 fd 后交 `WordCloud.to_file`）；
  2. `_replace_with_retry`：进程内 `threading.Lock` **串行化 `os.replace`**（临界区仅一次 rename），
     并对「目标正被读取」的占用错误做 **10 次 ×25ms** 有限重试；
  3. 任何结局都在 `finally` 清理临时文件，不留半截 PNG。
  回填词频同时按 `clean.json` / `analyze.json` 的 `st_mtime_ns` 做进程内记忆化
  （加锁、返回副本、128 条上限、只读不写回 detail），阶段产物更新后 mtime 变化自动重算。
- **复测**：直接函数 8 线程 ×5 轮 **40/40 成功**；live 端点 10 并发 ×6 轮 **0/60 失败**
  （修复前 46/60 失败），最终 PNG 960×600 可被 PIL 完整打开、目录无 tmp 残留。
  性能：旧任务 detail 冷算 1.66s → 记忆化后 **0.13–0.15s**；
  Python 词云图冷渲染 1.29s、缓存命中 **~6ms**。
  新增并发 / 重试 / 记忆化 3 个测试后全量 `pytest` **659 passed**。
- QA 其余 Low/Info 观察不阻断交付：CJK 文件名 ASCII 兜底退化（现代浏览器走 `filename*` 不受影响）、
  视频与数据项目非法参数校验顺序不同（均在契约允许范围）、`wordcloud` 缺失的 503 由单测覆盖。

## 六、已知说明

- 导出 CSV 使用标准 CSV 转义：评论正文里的逗号、引号、换行会出现在带引号的字段中，
  用 Excel / `csv` 模块读取行数准确（不要用 `splitlines()` 数行）。
- Python 词云图依赖 `wordcloud`（requirements.txt 已含）；缺失时接口返回 503、
  前端自动回退 ECharts；中文字体可用 `WORDCLOUD_FONT` 指定。
- 旧任务回填在 detail 请求时按 `clean.json` / `analyze.json` 的 mtime 记忆化：
  首次（进程启动后）约 1.7s，之后命中缓存 **0.13–0.15s**；只读、不写回 `<bvid>.json`；
  新分析的任务直接产出 60 词，无此开销。
