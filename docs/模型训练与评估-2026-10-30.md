# 正式模型训练与评估（2026-10-30）

## 本次结果

使用本机 Anaconda 的 `deeplearning` 环境，完成 Word2Vec、TextCNN 和 BiLSTM-Attention 的真实训练、
早停、测试集评估、错误分析和绘图。两种模型均运行 7 轮，验证准确率最高的检查点均位于第 4 轮。
权重重新加载后，重算整个测试集得到的各项指标与首次评估完全一致。

| 模型 | 最佳验证准确率 | 测试 Accuracy | 测试 Precision | 测试 Recall | 测试 F1 | 测试 Macro F1 |

Precision、Recall、F1 的正类为 positive=1；Macro F1 同时计入两类。
早停仅监控验证准确率，测试集不用于调整超参、轮次或分类阈值。

不能因此反过来选择超参或阈值。

混淆矩阵均以行表示真实类别、列表示预测类别，顺序为 [negative, positive]：

| 模型 | TN | FP | FN | TP |
| --- | ---: | ---: | ---: | ---: |
| TextCNN | 1922 | 160 | 270 | 1591 |

模型后几轮训练准确率继续上升，验证损失上升、验证准确率下降，已有过拟合迹象；

准确率曲线与混淆矩阵已目视确认中文显示及数值正确。

## Windows 复现

先在仓库根目录准备同一版本的数据；首次使用可运行 `python -m scripts.prepare_training_data`。
已有数据时应核对版本，不需反复覆盖预处理。

```powershell
$py = 'E:\Anaconda\envs\deeplearning\python.exe'
$env:PYTHONIOENCODING = 'utf-8'
$env:PYTHONHASHSEED = '42'
$env:CUBLAS_WORKSPACE_CONFIG = ':4096:8'
$env:OMP_NUM_THREADS = '4'
$env:MKL_NUM_THREADS = '4'

& $py -m src.embeddings --train-file data/splits/train.csv --vocab data/processed/vocab.json --out models/word2vec --embed-dim 128 --window 5 --min-count 3 --epochs 10 --workers 1 --seed 42
& $py -m src.training.cli --model textcnn --embeddings models/word2vec/embedding_matrix.npy --epochs 20 --batch-size 64 --lr 0.001 --max-len 200 --seed 42 --device cuda --patience 3
& $py -m src.training.cli --model bilstm_attention --embeddings models/word2vec/embedding_matrix.npy --epochs 20 --batch-size 64 --lr 0.001 --max-len 200 --seed 42 --device cuda --patience 3

# 与本次实验一样，将配套资源快照放到各模型目录。
foreach ($name in @('textcnn', 'bilstm_attention')) {
    $bundle = "models/checkpoints/$name/preprocessing"
    New-Item -ItemType Directory -Path $bundle -Force | Out-Null
    foreach ($file in @('vocab.json', 'preprocessor.json', 'label_map.json', 'manifest.json')) {
        Copy-Item -LiteralPath "data/processed/$file" -Destination $bundle
    }
}
```

环境已补齐 pytest、seaborn、wordcloud、FastAPI、python-multipart、openpyxl 等缺失依赖；没有重装 PyTorch。
训练产物默认被 .gitignore 忽略，源码推送不会同时上传权重。
训练命令会更新同名 best.pt；每轮实验应配套保存相应数据版本、源码、资源和指标，避免混用。
